# Smog Navigator — MVP

Personal air-quality advice, cleaner walking routes and smart alerts for Almaty (SDG 3.9 / 11.6).
Course project, Human–Computer Interaction, Team 1.

- Live: https://parzifalai.github.io/smog-navigator/
- Usability-test mode: https://parzifalai.github.io/smog-navigator/?test

Data: PM2.5 forecast — Copernicus Atmosphere Monitoring Service via Open-Meteo. Map and walking routes — © OpenStreetMap contributors.
The app gives advice, not a medical diagnosis.
